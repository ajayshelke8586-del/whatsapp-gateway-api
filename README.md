A high-performance, resilient WhatsApp Cloud API Gateway engineered by **[PANTHM AI Labs](https://panthm.com)** for automated enterprise communications, CRM synchronization, and post-call conversational routing.

---

## 🚀 Overview

Built to operate seamlessly alongside **[PANTHM Voice AI SDRs](https://panthm.com/solutions/b2b-outbound-ai-sdr)**:
- **Instant Post-Call Hand-off**: Automatically delivers meeting links, brochures, calendar confirmations, and pricing summaries on WhatsApp immediately after an outbound voice SDR call terminates.
- **Bi-directional Webhook Dispatcher**: Ingests incoming WhatsApp messages, validates HMAC-SHA256 signatures, and dispatches events to internal CRM webhooks (HubSpot, Zoho, Salesforce).
- **Template Management & Rate Limiting**: Token-bucket rate limiting adhering to Meta's tier constraints.
